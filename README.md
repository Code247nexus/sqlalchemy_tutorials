SQLAlchemy Learning Repository

This repository contains my hands-on learning of SQLAlchemy, covering both Core and ORM approaches.

📂 Structure
core/ → Implementation using SQLAlchemy Core (expression-based queries)
orm/ → Implementation using SQLAlchemy ORM (object-oriented approach) (comming soon)
🧠 Purpose

The goal of this repository is to understand:

How SQLAlchemy Core works internally
How ORM abstracts database operations
Differences between Core and ORM
🚀 Progression

Core → ORM 

📌 Note

This is a learning repository maintained for practice and future reference.
